## Что делает продукт

Пользователь вводит тикер — `SBER`, `AAPL`, `BTC`, любой рынок — и за 10–20 секунд получает структурированное аналитическое заключение из 13 блоков:

| Блок | Содержание |
|------|-----------|
| 01 | Что это — сектор, конкурентное преимущество, размер рынка, риски |
| 02 | Оценка стоимости — справедливая цена, запас безопасности, потенциал роста |
| 03 | Тренд 3/5/10 лет с ключевыми историческими событиями |
| 04 | Волны Кондратьева — позиционирование в длинном цикле |
| 05 | Макро и новости — ставки ЦБ, геополитика, заголовки |
| 06 | Технический анализ — RSI(14), SMA(50/200), уровни S1/R1 |
| 07 | Сентимент — Fear & Greed, стадия цикла, потоки капитала |
| 08 | Историческая аналогия — ATH, ATL, макс. просадка, восстановление |
| 09 | Потенциал роста — катализаторы, целевые цены |
| 10 | Индекс перегрева рынка — холодный / тёплый / перегретый |
| 11 | Профиль риска — волатильность, ликвидность, геополитика, долг |
| 12 | Крипто-метрики — активные адреса, NVT, TVL (только крипто) |
| 13 | План действий — зона покупки, целевая цена, стоп-лосс, ключевые тезисы |

**Ключевое отличие:** технические индикаторы (RSI, SMA, Pivot Points) рассчитываются из 260 реальных дневных OHLC-свечей детерминированным алгоритмом — не генерируются AI. Значения помечаются как `VERIFIED CALCULATED — NOT AI ESTIMATE` и проверяемы на TradingView.

## Архитектура

```
Пользователь вводит тикер
        │
        ▼
   Роутер источника данных
        │
        ├── Российская акция → MOEX ISS API (официальный, бесплатный)
        ├── US акция         → Yahoo Finance quoteSummary + chart
        ├── Крипто           → Binance 24hr + CoinGecko (fallback)
        └── Fallback         → Finnhub
        │
        ▼
   Технические индикаторы (серверная сторона, детерминированно)
   RSI(14) · SMA(50) · SMA(200) · Pivot Points S1/R1
        │
        ▼
   Промпт с верифицированными реальными данными
        │
        ├── Основной   → Anthropic Claude Haiku 4.5
        ├── Fallback 1 → OpenAI GPT-4o (при 5xx / timeout)
        └── Fallback 2 → Mistral Small (при ошибке OpenAI)
        │
        ▼
   Структурированный JSON → React фронтенд
```

Серверный кэш: 24ч TTL (Redis в распределённом режиме / in-memory Map как fallback).  
In-flight дедупликация: параллельные запросы на один тикер ждут первого ответа.  
Возврат квоты: атомарный откат через Supabase RPC при любом сбое.

## Ключевые возможности

**Анализ**
- 13-блочное структурированное заключение по любому активу
- Реальный RSI(14) из 260 дневных свечей по формуле Уайлдера
- Детектирование Golden Cross / Death Cross (SMA50 vs SMA200)
- Уровни поддержки и сопротивления из Pivot Points за 20 торговых дней
- Справедливая стоимость с запасом безопасности и потенциалом роста

**Российский рынок**
- Официальный API Московской биржи (MOEX ISS, без ключа)
- Сравнение дивидендной доходности с ключевой ставкой ЦБ
- Бенчмарк ОФЗ / банковский депозит в каждом анализе RU-бумаг
- Контекст ИИС-3 и НДФЛ 13–15%
- Санкционные риски (НРД/Euroclear) для затронутых активов

**Портфель**
- Отслеживание P&L по каждой позиции
- Сравнение с S&P500 и BTC (BenchmarkWidget)
- Автобэктест: прогнозы верифицируются по реальным ценам через 30 дней
- Торговый журнал

**Алерты и уведомления**
- Ценовые алерты через email + Telegram-бот
- Еженедельный P&L дайджест (понедельник, распределённый Redis-лок)
- Telegram: `/start` `/link CODE` `/alerts` `/remove TICKER`

**Платформа**
- Публичная страница точности AI `/accuracy` — каждый прогноз логируется и верифицируется
- Шаринг анализа через ссылку с OG-превью в Telegram/X (TTL 30 дней)
- Скринер активов — 20+ позиций с AI-сигналами
- Сравнение 2–3 активов side-by-side
- Developer API с управлением ключами и квотой на ключ
- Реферальная программа (+3 анализа обеим сторонам)
- Двуязычный интерфейс — русский и английский

## Безопасность

- JWT HS256 с timing-safe сравнением — без сторонних auth-библиотек
- ЮКасса webhook: IP-вайтлист + независимая верификация через `GET /v3/payments/{id}`
- Redis sliding-window rate limiting через атомарный Lua-скрипт
- Распределённые локи для cron-задач через Redis NX
- Атомарное управление квотой — refund RPC при любом сбое
- `res.on('error', reject)` на всех HTTP response-хендлерах
- CSP · HSTS · X-Frame-Options · X-Content-Type-Options в продакшне
- Лимиты тела запроса: 64KB запрос / 256KB ответ
- Защита от path traversal при раздаче статики

## Установка

### Требования
- Node.js 18+
- Supabase проект
- Anthropic API ключ

### Установка

```bash
git clone https://github.com/kaltuzetas/ai-investment-analyst
cd ai-investment-analyst
npm install
```

### Настройка

```bash
cp .env.example .env
# Заполнить необходимые переменные
```

### Запуск

```bash
# Разработка
npm run dev    # Vite фронтенд — http://localhost:5173
node proxy.js  # Backend proxy — http://localhost:3001

# Продакшн
npm run build
npm start
```
